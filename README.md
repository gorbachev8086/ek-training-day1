## 게시

GitHub 저장소의 Settings → Pages → Deploy from a branch → main → /(root)를 사용합니다. 이 폴더의 `index.html`, `slides.json`, `.nojekyll`, `assets`를 함께 게시합니다.

## 로컬 미리보기

이 폴더에서 Python이 설치된 PC는 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`을 엽니다. JSON을 읽는 웹 페이지이므로 HTML만 더블클릭하는 방식은 지원하지 않습니다.
